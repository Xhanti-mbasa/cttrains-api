## In this update
- Refined Smart Cards and next-trip widgets: separated title and clock, compact layout, useful setup/refresh states and buttons that stay visible.
- Dismissible update banners once per available version, a first-install explanation, and recurring security notices for specifically affected builds.
- Developer options behind seven taps on the Settings version label. Requires the owner's separately configured developer-control service and a valid server code. The APK contains no master code or invitation list.
- Local developer diagnostics, screen/feature controls and owner-only access management. Temporary test-build maintenance expires automatically and keeps settings, backups and updates accessible; it cannot affect older builds that lack the feature.
- Preparation for a separately installed CT Trains Lab edition. The redesigned experimental APK is not available yet.
